# picopostreader

# UNFINISHED!

Stop-gap solution to read xbox 360 POST codes with a Pi Pico PIO.

Uses GPIO 0-7, connect directly to post bits 0-7.

Includes an example reading script in python for Linux and Windows


## Background

None of the PicoFlasher versions have POST reading? Neither does the xFlasher360?

I need to debug gxBuild images and id rather not manually read the post bits with a multimeter.
